2. Scope of Disclosure

RFC-FTS-0001 describes public conceptual and research material associated with the Fractal Time Standard (FTS), including:

* generalized discussion of temporal-alignment challenges, including leap-second and drift-related issues;
* the symbolic expression τ · Φ · Ψ³ = 86 400 s, presented within the conceptual and philosophical framework of the public draft;
* high-level research goals;
* public validation references available at the time of publication; and
* community research and collaboration guidance.

The publication does not intentionally disclose the proprietary computational implementation, protected parameters, internal phase relationships, production source code, private constants, credentials, or other confidential implementation material used by the GAL-2 Protected Core.

6. Relationship to Current GAL-2 Architecture

RFC-FTS-0001 preserves an early public research description of the Fractal Time thesis.

The current GAL-2 implementation separates the protected mathematical engine from the application-facing operational surfaces:

Reference inputs → Protected Core → GAL-2 Time → GAL-2 API → GAL-2 Node → Time Contract → enrolled application

The Protected Core creates GAL-2 Time.
The GAL-2 API delivers GAL-2 Time.
GAL-2 Node makes GAL-2 Time locally consumable.
The Time Contract governs whether an enrolled application should consume it.

The proprietary Protected Core and Fractal Time implementation are not disclosed by RFC-FTS-0001.

Current product architecture, documentation, and validation materials may therefore evolve beyond the terminology and implementation status reflected in the October 2025 public draft.
